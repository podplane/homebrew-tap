# Homebrew Tap for Podplane

This repository is the Homebrew tap for the Podplane CLI.

## Install

```bash
brew install podplane/podplane
```

## Release Process

The [`podplane/podplane`](https://github.com/podplane/podplane) release workflow updates this tap with the latest generated formula when a `v*` tag is published.
